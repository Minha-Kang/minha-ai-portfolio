# Google Drive 자료 선별 인덱스

이 문서는 공개 저장소에 포함할 자료와 원본 Drive 자료의 관계를 기록합니다. Drive 링크와 원본 파일은 공유 설정에 따라 별도 접근 권한이 필요할 수 있습니다.

## 선별 원칙

1. 프로젝트별로 최신·최종 자료를 한 개 이상 남깁니다.
2. 코드가 있는 프로젝트는 실행 코드와 검증 문서를 우선합니다.
3. 발표자료가 여러 버전이면 최신본만 대표 자료로 연결합니다.
4. 대용량 원본 데이터, 중복 결과, 캐시, 임시본, 전체 로그는 저장소에서 제외합니다.
5. 개인정보, API key, `.env`는 포함하지 않습니다.

## 제외한 자료 유형

- `수정 전`, `이전본`, `중간본`, 동일 내용의 중복 파일
- `__pycache__`, cache Arrow, 전체 실행 log, 대용량 raw dataset
- 외부 논문의 원본 코드·paper asset 자체
- 이름·학번만 표시된 overlay나 지원에 직접 도움이 되지 않는 임시 파일

## 공개 저장소 해석 기준

- `코드 포함`: 저장소에서 구현 구조를 확인할 수 있으나, 제외된 입력 데이터가 있으면 end-to-end 재현에는 추가 자료가 필요합니다.
- `요약 데이터 포함`: 직접 수행한 EDA 결과를 CSV로 확인할 수 있습니다.
- `README와 원본 링크`: 분석·설계의 범위와 산출물 위치를 설명하며, 실행 가능한 코드 패키지를 의미하지 않습니다.
