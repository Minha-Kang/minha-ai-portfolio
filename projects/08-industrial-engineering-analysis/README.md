# Project 08. Reliability Engineering & Human Factors Analysis

*산업공학 기반 수명 데이터 및 인간 중심 작업환경 분석*

AI 프로젝트 외에 산업공학의 기본인 수명 데이터 해석과 인간 중심의 작업·사용 환경 개선 경험을 정리한 프로젝트입니다.

## 8A. Repeated-Bending Lifetime Analysis of Paper Clips

- 클립의 반복 굽힘 횟수와 파손 데이터를 다룬 신뢰성공학 팀 프로젝트
- 관측된 수명 분포와 반복 파손 특성을 분석
- 분석 과정과 결과를 팀 발표 자료로 구조화

이 프로젝트를 통해 평균만 비교하는 것이 아니라 수명 데이터의 변동성과 파손 시점을 함께 해석하는 신뢰성공학 관점을 적용했습니다.

## 8B. Human Factors Analysis for Work-System Improvement

- 사용자와 작업 환경에서 발생하는 불편·위험 요인 관찰
- 문제를 인간공학 관점에서 구조화
- 관찰 근거를 설계·운영 개선안과 보고서로 연결

## 공개 범위

현재 저장소에는 원본 측정 데이터와 분석 코드가 아니라 수행 내용과 대표 자료 위치를 정리했습니다. 정량 결과를 새로 재현하는 패키지가 아닌 산업공학 문제 해결 경험을 설명하는 포트폴리오 자료입니다.
