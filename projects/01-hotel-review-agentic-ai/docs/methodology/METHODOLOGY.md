# 호텔별 Review-derived IPA 프로토타입

## 분석 단위

- 메인 IPA 점: 호텔 × Feature
- Journey: 집중 개선 Feature의 2차 진단 단위
- 동일 리뷰에서 같은 Feature가 여러 번 검출되어도 리뷰 1건으로 집계

## 표본 규칙

- 호텔 리뷰 수 30개 이상만 독립 IPA 생성
- Feature 언급 리뷰 5개 미만은 근거 부족
- 집중 개선 후보는 부정 리뷰 3개 이상
- 현재 1,000개 표본에서 적격 호텔은 7개

## 성과축

성과는 Feature별 평균 감성(-2~+2)을 사용한다. 작은 표본의 극단값을 줄이기 위해 전체 Feature 평균을 prior로 두고 strength 5로 수축한다. 차트의 X축은 호텔 수축 성과 - 전체 동일 Feature 성과를 100점 척도로 환산한 값이다. 0보다 작으면 전체 벤치마크보다 성과가 낮다.

## 중요도축

중요도는 `부정 발생률 × 평점 패널티`를 결합한 탐색적 대리치다.

`100 × 수축된 호텔 부정 발생률 × 수축된 호텔 평점 패널티 ÷ 4`

- 부정 발생률은 호텔 전체 리뷰 중 해당 Feature가 부정적으로 나타난 리뷰의 비율이며, 작은 표본의 극단값을 줄이기 위해 전체 Feature 발생률을 prior로 두고 수축한다.
- 평점 패널티는 같은 호텔 안에서 해당 Feature가 부정적인 리뷰와 그 밖의 리뷰 간 평균 평점 차이다.
- Feature별 호텔 내부 평점차를 random-effects meta-analysis로 결합한 뒤, 호텔별 직접 추정치를 유효 표본크기에 따라 결합값 쪽으로 부분 수축한다.
- 음의 패널티는 0, 4점을 넘는 패널티는 4로 제한한다.

이 값은 우선순위 선별을 위한 연관성 지표이며 인과효과로 해석하지 않는다. 논문 확증분석에서는 다층 회귀나 예측모형의 marginal effect와 비교하는 것이 바람직하다.

## 사분면

- 수직 기준선: Feature별 전체 벤치마크 대비 성과 차이 0
- 수평 기준선: 해당 호텔에서 표본 기준을 충족한 Feature 중요도의 중앙값
- Q1 유지 강화: 중요도가 높고 성과도 높은 Feature
- Q2 집중 개선: 중요도가 높지만 성과는 낮은 Feature
- Q3 낮은 우선순위: 중요도와 성과가 모두 낮은 Feature
- Q4 과잉 가능: 중요도는 낮지만 성과는 높은 Feature
- NA 근거 부족: Feature 언급 리뷰가 5개 미만인 경우

## 안정성 선별

- 적격 호텔의 리뷰를 복원추출해 호텔별 500회 bootstrap을 수행한다.
- 관측 결과가 Q2이고, bootstrap에서 Q2가 될 확률이 0.70 이상이며, 부정 리뷰가 3개 이상인 Feature만 `안정 Q2`로 채택한다.
- Journey 세분화와 개선안 연결은 안정 Q2에만 수행한다.

## 개선안 연결과 역추적

- 새 LLM/API 호출 없이 기존 Agent 6 결과를 같은 `호텔-Feature-Journey-리뷰 ID`에 우선적으로 정확 매칭한다.
- 각 우선순위에는 호텔 리뷰 수, Feature 언급·부정 리뷰 수, Journey 부정 리뷰 수와 평균 별점, 평점 격차, 근거 문장과 원 리뷰 ID를 함께 보존한다.
- 개선안은 검증된 처방으로 주장하지 않고, 우선순위 진단에서 도출 가능한 활용 사례로 제시한다.

## 해석 한계

- 고정 1,000개 표본은 호텔별 추정을 목적으로 설계되지 않았다.
- 리뷰 기간이 2015-01-03~2025-03-15로 길어 현재 운영상태와 과거 운영상태가 섞인다.
- 본 결과는 방법론 시범이다. 최종 분석은 원본 데이터에서 최근 기간과 호텔별 최소 표본을 먼저 적용한 뒤 다시 실행해야 한다.
