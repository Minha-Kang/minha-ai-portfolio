# Project 02. Who&When 기반 Multi-Agent Failure Attribution 분석

## 개요
멀티에이전트 시스템이 실패했을 때, 실패 책임 agent가 누구인지와 결정적 오류 step이 언제인지 분석한 프로젝트입니다.

## 폴더 구성
- 00_original_all_files: Agents_Failure_Attribution 원본 폴더 전체를 보존했습니다.
- 01_portfolio_named_key_files: 발표자료, 보고서, README, requirements, 핵심 코드 파일을 한글 설명 파일명으로 정리했습니다.
- 02_portfolio_named_eda_outputs: Who&When EDA CSV 산출물을 보관했습니다.
- 03_assets_for_portfolio: 논문 그림, 저장소 이미지, paper PDF 등 설명용 자료입니다.

## 설명 문장
본 프로젝트에서는 Who&When 데이터셋과 Automated Failure Attribution 코드를 분석하여, LLM 기반 multi-agent system의 실패 원인을 agent와 step 단위로 추적했습니다.
단순히 최종 정답 여부만 보는 것이 아니라, failure-responsible agent와 decisive error step을 분리해 평가하는 구조를 정리했습니다.
이후 조건 손실과 약한 성공이라는 trajectory quality 관점으로 연구 질문을 확장했습니다.
