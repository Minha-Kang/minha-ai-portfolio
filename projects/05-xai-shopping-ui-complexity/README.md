# Project 05. XAI-Based UI Complexity Diagnostics with AndroidControl

*Original team project: XAI-Based UI Complexity Diagnostics for Better Shopping App Design*

쇼핑 앱의 화면 구성과 사용자 경험을 설명 가능한 방식으로 분석하고, 모델의 판단을 UI 개선 방향으로 연결한 팀 프로젝트입니다.

## 문제 정의

UI 복잡도 모델이 단순히 “복잡하다”는 점수만 출력하면 디자이너가 무엇을 바꿔야 하는지 알기 어렵습니다. 화면 특성과 사용자 행동을 함께 정의하고, 예측에 중요하게 작용한 요소를 설명해 실제 개선 항목으로 변환하는 것을 목표로 했습니다.

## 수행 내용

- 쇼핑 앱 화면의 복잡도를 구성하는 시각·정보·행동 특성 정의
- 예측 결과뿐 아니라 중요한 UI 요소를 해석하는 XAI 기반 분석 흐름 설계
- 해석 결과를 정보 배치, 탐색 흐름, 가독성 개선 방향으로 연결
- 팀 프로젝트의 자료 조사, 분석 구조화, 결과 문서화 참여

## 산출물의 의미

이 프로젝트는 특정 XAI 점수를 최종 제품에 배포한 사례가 아니라, UI 복잡도 예측과 설명을 서비스 개선에 연결하는 분석 프레임을 제안한 수업 팀 프로젝트입니다. 공개 저장소에는 발표 요약만 포함하며, 원본 데이터·학습 코드·정량 성능표는 포함하지 않았습니다.
