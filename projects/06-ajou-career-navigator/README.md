# Project 06. Ajou Career Navigator

아주대학교 대학일자리플러스센터의 서비스를 학생의 학년뿐 아니라 실제 취업 준비 행동과 이용 이력에 따라 연결하는 데이터 기반 맞춤화 서비스 제안입니다.

## 문제 정의

같은 학년의 학생도 진로 탐색, 직무 역량 개발, 지원 준비, 불안 수준과 서비스 이용 정도가 다릅니다. 일괄적인 프로그램 안내 대신 학생의 현재 상태를 데이터로 구분하고, 다음 행동과 지원 서비스를 개인화하는 구조를 설계했습니다.

## 분석 설계

- 입력 후보: 서비스 이용 로그, 상담·검사 데이터, 희망 직무, 준비 행동, 만족도 텍스트
- 세분화: clustering으로 행동·수요가 유사한 학생군 탐색
- 관계 분석: association analysis로 서비스 이용 순서와 조합 파악
- 텍스트 분석: TF-IDF·sentiment analysis로 상담·후기 신호 추출
- 예측: classification/regression으로 이탈, 참여, 만족도 등 목표 변수 추정

## 제안한 학생 세그먼트

- 진로탐색형
- 직무역량개발형
- 실전취준형
- 취업불안형
- 서비스저이용형
- 특수수요형

세그먼트는 실제 운영 데이터로 확정된 군집 결과가 아니라, 분석과 서비스 설계를 위한 초기 가설입니다.

## 서비스 구조

학생 특성과 프로그램 적합도를 결합하는 `Career Fit Score` 개념을 설계하고, 점수와 세그먼트에 따라 다음 접점을 다르게 제안했습니다.

- 학생 dashboard: 현재 준비 단계와 추천 행동 표시
- 상담사 화면: 학생별 우선 확인 항목과 상담 이력 요약
- 프로그램 추천: 목표 직무·준비도·과거 참여를 반영한 우선순위
- 알림: 학생 상태에 맞는 시점과 메시지 차별화

## 현재 단계와 공개 범위

본 프로젝트는 서비스 기획·분석 설계 단계의 제안입니다. 실제 대학 운영 데이터로 모델을 학습하거나 서비스를 배포한 결과는 아니며, 공개 저장소에는 개념·방법·산출물 링크를 정리했습니다.
